# SignPath notes

The earlier version of this file prepared a SignPath Foundation (free, open-source) application. That program requires an OSI-approved license with no commercial dual-licensing (https://signpath.org/terms), which the iii3xnz Sustainable Use License and Enterprise License do not satisfy, so the application is no longer pursued.

A paid SignPath plan or another Authenticode certificate can still be used through the optional signing step in `.github/workflows/release.yml`; see CODE_SIGNING.md. Do not claim adoption or reputation that public evidence does not support.
