# Contributing to iii3xnz

1. Fork the repository and create a focused branch.
2. Run the backend tests with a disposable PostgreSQL database.
3. Run `npm run build` in `frontend`.
4. Keep secrets out of source, tests, commits, and issue reports.
5. Include regression coverage for behavior changes.
6. Open a pull request describing the security and operational impact.
